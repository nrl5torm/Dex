## Commits

- Use Conventional Commits: feat:, fix:, refactor:, docs:, or chore:.
- Keep the subject under 72 characters.
- Write subjects in the imperative: "Add search filters".
- Run a build before committing Swift changes.
- Never commit API keys, signing certificates, or local Xcode user settings.
- Include the issue number when one is provided.
- Do not push unless the user asks.
